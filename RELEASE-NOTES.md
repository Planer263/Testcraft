# Launch Login 1

Dedicated password login at website launch; separate first-run account creation;
Enter-key login; visible errors; remembered account selection but no stored game
password; sign-out/switch account; encrypted-account backup import/export.
No cryptographic vault-format or player-ID migration is performed. Old Unlock /
Lock controls are no longer shown. Existing game saves and records are retained.
The standalone startup/graphics recovery protections are included.

See LOGIN-START-HERE.md and docs/LAUNCH-LOGIN-TESTS.json. Earlier reports describe
their respective earlier builds, not exhaustive validation of this release.
